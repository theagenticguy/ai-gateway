# ai-gateway · Engineering docs

Deep-dive documentation for the ai-gateway codebase, generated by a fleet of analysis agents that read the source directly and cite every claim with a `` `path:LOC` `` reference. Prose is generated; structure is mechanical; cross-references are deterministic. Grounded against `main` and the CodeGraph index at the repo root.

This tree is a snapshot of the codebase at generation time. Line numbers and LOC figures drift as the code moves; spot-fixes are applied when a claim becomes actionably wrong, but the tree is not regenerated on every change. Verify line-level citations against the current source before acting on them.

For getting-started, admin, and reference guides, see the published Starlight site under `docs/`. This tree answers the deeper questions: how the pieces fit, what the code assumes, how it fails, and what breaks when you change it.

## What this tree deliberately omits

Four candidate documents were skipped because their subject does not exist here or the signal would mislead:

- **RPC/tools reference** — the runtime is server-only (Lambda handlers + an agentgateway data plane); there is no RPC/MCP tool server to document. (A CLI reference was originally skipped for the same reason, but a standalone operator CLI does exist under `clients/admin_cli/`, so it is now documented at [reference/cli.md](reference/cli.md).)
- **Ownership**, **risk hotspots**, and **dead-code** analysis — git history is effectively single-author plus bots, and the services are Lambda entry points that nothing imports, so naive authorship, churn, and unreferenced-export signals produce false conclusions rather than useful ones.

## Notable findings surfaced during generation

Three consistency gaps were surfaced at generation time. All three have since been resolved by issues #260-#262 (PR #264); the historical statements are kept here because the linked docs still discuss them:

- **Two disagreeing tier-budget tables.** `team_registration` seeded budgets from FREE/STANDARD/PREMIUM/ENTERPRISE while `budget_enforcement` used sandbox/standard/premium/unlimited with different amounts. Resolved: tiers now have one source of truth, `src/gwcore/tiers.py` (sandbox/standard/high/unlimited), imported by every service. See [business-logic](insights/business-logic.md).
- **Admin-created budgets were invisible to enforcement.** `budget_admin` wrote budgets under a different DynamoDB key schema than `budget_enforcement` read. Resolved: every service now reads and writes the real Terraform table schemas (`budget_id`/`scope` plus the `scope-index` GSI for budgets; `scope_id`/`period_date` for usage). See [contract-map](insights/contract-map.md).
- **Silent IaC waivers.** The CI checkov `skip_check` list hard-suppressed six findings absent from the justified `.checkov.yml`. Resolved: all 28 skips now live in `.checkov.yml` with per-code rationale, and CI consumes that file. See [tech-debt](insights/tech-debt.md).
